# BCU Framework Test

## Instructions

To run the tests, do the following:

- Open a Windows command-prompt
- Run `run_tests_cunit.cmd` to run the C-Unit tests
- Run `run_tests_tpt.cmd` to run the TPT tests
- Before archiving the project, run `clean.cmd` to delete the intermediate files

## Further information

For more information on BCU, see the [BCU Framework Community](https://connect.bosch.com/communities/community/bcu) in Bosch Connect.
